# Axium Group

Site marketing Next.js (TypeScript, Tailwind, shadcn/ui) pour Axium Group.

## Lancer en local

```bash
npm install
npx next dev --hostname 0.0.0.0 --port 4721
```

Ouvrir [http://127.0.0.1:4721](http://127.0.0.1:4721).

Production : [https://axium-three.vercel.app](https://axium-three.vercel.app) (projet Vercel `axium`).
